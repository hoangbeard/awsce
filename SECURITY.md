# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's
[private vulnerability reporting](../../security/advisories/new) instead.

You can expect an acknowledgement within 5 business days. This is a personal
project maintained on a best-effort basis; there is no bug bounty.

## Scope

Example credentials, keys and tokens in this repository are placeholders or
intentionally fake training data. If you find something that looks real,
please report it as above.
